B — تحديد Availability Contract
==================================================

ثبت العقد الفعلي:

teacher_profiles.available_days
teacher_profiles.available_from
teacher_profiles.available_to

ثم حدد:

- صيغة الأيام.
- صيغة الوقت.
- هل available_to شامل؟
- هل available_to يمثل بداية آخر slot أم نهاية نافذة التوفر؟
- هل مدة الجلسة تدخل في الحساب؟
- هل 30 دقيقة و45 دقيقة و60 دقيقة تتعامل معها المنصة كيف؟
- هل slot start + duration <= available_to؟
- ماذا يحدث إذا كانت المدة تتجاوز availability؟
- ماذا يحدث إذا كان اليوم غير موجود؟
- ماذا يحدث إذا كانت Availability NULL؟
- هل المنصة ترفض أم تعرض fallback؟
- هل API يرفض أم Mobile فقط؟
- هل Database/RPC تفرض ذلك؟

كل إجابة يجب أن تكون مدعومة من الكود أو قاعدة البيانات.

C — Specific Teacher Booking
==================================================

راجع المسار كاملاً:

Student
→ Teacher
→ Subject
→ Date
→ Time
→ Duration
→ booking_requests
→ Accept
→ bookings

ثبت:

- هل المعلم المحدد فقط يستقبل الطلب؟
- هل booking_requests تحتوي teacher_id؟
- إذا لم تحتوي teacher_id، كيف تعرف المنصة المعلم المقصود؟
- هل هناك metadata أو relation أخرى؟
- هل API الحالي يرسل teacher_id؟
- هل Database تحفظه؟
- هل RLS تمنع باقي المعلمين؟
- هل الإشعار فقط هو الذي يحدد المعلم؟
- هل هذا يعني أن الطلب ليس معزولاً فعلياً؟

هذه نقطة حرجة.

إذا كانت المنصة نفسها لديها limitation في schema:

لا تخترع workaround.

صنف:

PLATFORM LIMITATION

ووضح أثرها.

G — Race Conditions
==================================================

راجع First Accept Wins.

أريد تحديد:

- هل RPC الحالي atomic؟
- هل يستخدم transaction؟
- هل يستخدم conditional update؟
- هل يتحقق من status قبل القبول؟
- هل يمكن طلبين قبول نفس الطلب؟
- ماذا يحدث إذا ضغط معلمان Accept في نفس اللحظة؟
- هل booking يتم إنشاؤه قبل أو بعد تغيير status؟
- هل توجد UNIQUE constraints؟
- هل يوجد locking؟
- هل يمكن إنشاء booking مزدوج؟

إذا لم نستطع إثبات ذلك بدون Production:

صنف:

RACE CONDITION = PRODUCTION UNVERIFIED

ولا تدعي أنه BLOCKED إلا إذا كان هناك سبب محدد يمنع الاختبار.
