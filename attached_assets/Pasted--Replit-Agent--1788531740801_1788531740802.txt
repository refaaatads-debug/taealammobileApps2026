تمام. **الخطوة التالية الآن هي الحجز، وليس إعادة فحص ما تم إنجازه.**

أعطِ Replit Agent هذا البرومبت:

> **أكمل المرحلة التالية: نظام الحجز فقط، مع شرط أمان صارم.**
>
> اجعل تطبيق الهاتف يطابق **منصة الويب الأصلية 100%** في دورة الحجز، باستخدام نفس Supabase Production ونفس الجداول وRPC وEdge Functions والمنطق الموجود في المنصة الأصلية.
>
> **ممنوع منعاً باتاً:**
>
> * تعديل منصة الويب الأصلية.
> * تعديل VPS أو Nginx أو Kong أو GoTrue.
> * تعديل Database / Schema / RLS / RPC / Triggers / Functions.
> * إنشاء جداول أو بيانات بديلة.
> * تغيير أي خاصية أو سلوك موجود في المنصة الأصلية.
> * تنفيذ أي عملية كتابة على Production أثناء مرحلة المطابقة.
>
> **المطلوب:**
>
> 1. اقرأ كود المنصة الأصلية وحدد دورة الحجز الحقيقية من البداية للنهاية.
> 2. طابق التطبيق مع نفس:
>
>    * اختيار المعلم.
>    * المادة.
>    * المرحلة.
>    * الأيام والأوقات المتاحة.
>    * إنشاء طلب الحجز.
>    * `booking_requests`.
>    * قبول المعلم.
>    * رفض المعلم.
>    * تحويل الطلب إلى الحجز المؤكد.
>    * الإلغاء وإعادة الجدولة.
>    * الإشعارات.
>    * ربط الحجز بالطالب والمعلم.
>    * الاشتراك والدقائق المستخدمة.
> 3. استخدم **نفس RPC / API / Edge Functions الموجودة في المنصة الأصلية** ولا تنشئ منطقاً بديلاً.
> 4. تحقق من أن التطبيق يقرأ ويكتب بنفس الحقول والقيم والحالات التي تستخدمها المنصة.
> 5. افحص منع الحجز المكرر وتعارض المواعيد وعدم كفاية الرصيد بنفس شروط المنصة.
> 6. راجع كل شاشة مرتبطة بالحجز في التطبيق مقابل كود المنصة الأصلية.
> 7. نفّذ التعديلات **داخل مشروع التطبيق فقط**.
> 8. بعد كل تعديل شغّل TypeScript/build/tests وتأكد أن التطبيق يعمل.
>
> **قاعدة أساسية:**
> إذا وجدت أن تنفيذ المطابقة يتطلب أي تغيير في Production أو المنصة الأصلية أو قاعدة البيانات، **توقف فوراً ولا تنفذ التغيير**، واكتب لي اسم التغيير المطلوب وسبب احتياجه.
>
> في النهاية أعطني تقريراً مختصراً:
>
> * ما الذي تمت مطابقته.
> * الملفات التي تغيرت في التطبيق.
> * ما الذي لم يتم مطابقته.
> * أي فروقات متبقية.
> * تأكيد صريح أن **صفر تغييرات** تم إجراؤها على المنصة الأصلية وProduction Database.

**وبعد اكتمال الحجز ننتقل بالترتيب إلى: الجلسات والمكالمات → الباقات/الاشتراكات → المحفظة والفواتير → الإشعارات → المحادثات.**
