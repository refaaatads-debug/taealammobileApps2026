لدينا الآن وصول كامل إلى:

1. GitHub — كود المنصة الأصلية.
2. VPS — البيئة والخدمات والـAPI الخاصة بالمنصة.
3. Supabase Production — نفس قاعدة البيانات المستخدمة في المنصة.
4. API والـbackend.
5. RPC/Database Functions الموجودة أصلًا.
6. Schema والعلاقات والصلاحيات.

لذلك لا أريد منك بناء منطق بديل للتطبيق.

اعتبر المنصة الأصلية هي SOURCE OF TRUTH بنسبة 100%.

المطلوب:
اجعل تطبيق Android/iOS Mobile Client للمنصة الأصلية، وليس نظامًا جديدًا مشابهًا لها.

قبل أي تعديل:
اعمل Reverse Engineering كامل للمنصة الأصلية.

تتبع كل عملية بهذا الشكل:

واجهة المنصة
→ Component
→ API/Service
→ Backend endpoint
→ RPC/Function إن وجدت
→ Supabase tables
→ العلاقات
→ RLS/permissions
→ النتيجة التي تظهر للمستخدم.

ثم اجعل التطبيق يستخدم نفس المنطق والـAPI/RPC الموجود أصلًا كلما كان ذلك ممكنًا.

ممنوع اختراع Query أو Business Logic بديل إذا كان هناك منطق أصلي في المنصة.

خصوصًا:

الحجز:
- استخدم نفس خطوات المنصة.
- نفس شروط ظهور المعلمين.
- نفس فلترة المعلمين.
- نفس المواد.
- نفس التوفر.
- نفس المواعيد.
- نفس booking_requests.
- نفس RPC لقبول/رفض الطلب.
- نفس حالات الحجز.
- نفس الإشعارات.
- نفس الإلغاء وإعادة الجدولة.

الباقات:
- نفس subscription_plans.
- نفس user_subscriptions.
- نفس حساب الدقائق/الجلسات.
- نفس شروط صلاحية الباقة.
- نفس منطق الخصم.
- نفس منطق الإرجاع والتعويض.
- نفس الفواتير والمدفوعات والمحفظة.

الجلسات:
- نفس إنشاء الجلسة.
- نفس الحالة.
- نفس البداية والنهاية.
- نفس احتساب المدة.
- نفس التعويضات.
- نفس غرفة الجلسة.

المستخدم:
المستخدم في التطبيق والمنصة يجب أن يكون نفس الحساب ونفس user ID.
لا تنشئ نظام مستخدمين منفصل.

مثال:
إذا كان الطالب لديه:
20 جلسة على المنصة
ثم استخدم التطبيق
يجب أن يرى نفس الـ20 جلسة.
إذا حجز جلسة من التطبيق، يجب أن يظهر الحجز في المنصة.
إذا ألغى الحجز من المنصة، يجب أن يتغير في التطبيق.

نفس الأمر للمعلم.

مهم جدًا:
لا تنشئ قاعدة بيانات ثانية.
لا تنشئ جداول بديلة.
لا تنسخ Production.
لا تنشئ Mock Data.
لا تعدل Schema.
لا تعدل RLS.
لا تعدل RPC Functions الموجودة.
لا تغير بيانات Production أثناء الفحص.

في البداية READ-ONLY فقط.
