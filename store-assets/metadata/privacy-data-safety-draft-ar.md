# مسودة إفصاحات الخصوصية وData Safety — للمراجعة وليست اعتمادًا نهائيًا

> لا تُنسخ هذه المسودة مباشرة إلى Google Play Console أو App Store Connect. هي جرد أولي من كود الهاتف وAPI والوثائق المحلية، وليست إقرارًا قانونيًا أو مراجعةً لكل خدمات الإنتاج. تحقّق من مزودي الخدمات الفعليين، وجهة المعالجة، الاحتفاظ، الحذف، وأي تدفقات تعمل في Supabase Edge Functions أو خارج المستودع.

## مزودو الخدمة الظاهرون أو المحتملون

- **Supabase:** يظهر استخدام SDK للمصادقة والبيانات والتخزين. طابق ذلك مع إعدادات ومخازن الإنتاج وسياسة كل مزود.
- **Agora وWebRTC:** SDKs للجلسات الصوتية/المرئية والاتصال. لا تفترض أن البيانات لا تُسجل إلا بعد التحقق من إعدادات التسجيل والـ cloud recording الفعلية.
- **Expo Push / Firebase / APNs:** التطبيق يطلب رموز إشعار ويسجلها عبر API؛ ملف Google Services وإضافة Expo Notifications موجودان. حدّد بيانات الرمز ومشاركة المزود حسب المنصات.
- **Stripe:** صفحة الاشتراك تستدعي Edge Function باسم `create-checkout` وتفتح الرابط الخارجي المُعاد. لا تكتب أن التطبيق يجمع بيانات البطاقة دون إثبات ذلك.
- **Twilio:** توثيق معماري محلي يصف مكالمات هاتفية عبر Twilio ووظائف webhooks؛ مستودع التطبيق وAPI المحلي لا يعرض كود المزود نفسه. تعامل معه كـ **يحتاج تحققًا** لا كمسار مؤكد حاليًا.
- **التحليل والإعلانات والأعطال:** لم يظهر في البحث المبدئي SDK تحليلات/إعلانات واضح. سياسة التطبيق تذكر سجلات الأعطال وبيانات تقنية؛ تحقّق من النقل والتخزين الفعلي قبل إعلان «لا يجمع» أو «لا يتتبع».

## أسئلة يجب حسمها في نموذج Data Safety وApp Privacy

1. هل تجمع المنصة عنوانًا أو إحداثيات دقيقة؟ وهل تُشاركها مع المعلم بعد قبول الحصة الحضورية؟
2. هل تُخزن التسجيلات الصوتية/المرئية أو السبورة أو مرفقات الجلسة؟ ومن يمكنه الوصول إليها؟
3. هل بيانات المعلم المالية تشمل رقم حساب/IBAN أو وسيلة دفع أو بيانات ضريبية؟ ما الجهة التي تستقبل كل حقل؟
4. ما البيانات التي تتلقاها Supabase وVPS وExpo/FCM/APNs وAgora وTwilio وStripe فعليًا؟ وما فترات الاحتفاظ والحذف عند كل مزود؟
5. هل تُرسل أي معرفات أو بيانات لاستخدام الإعلانات أو قياسها؟ لم يظهر ذلك في الفحص، لكن يلزم تأكيد مسؤول المنتج ومزودي الإنتاج.
6. ما سياسة الأعطال والسجلات على VPS وSupabase، وهل تتضمن IP أو محتوى طلبات أو معرفات حساب؟
7. ما العمر الأدنى والجمهور المستهدف؟ سياسة الخصوصية داخل التطبيق تشير إلى احتمال القاصرين وموافقة ولي الأمر، لكن ذلك لا يحسم تصنيف المتجر أو Kids Category.

## حالة الحذف والمراجعة

- لا يظهر إجراء حذف الحساب الكامل في شاشة الملف الشخصي التي فُحصت؛ الرابط الحالي يفتح الدعم.
- سياسة الخصوصية داخل التطبيق تذكر حق طلب حذف الحساب أو البيانات عبر مركز الدعم.
- مسارات الموقع العامة `/privacy`, `/support`, و`/delete-account` أعادت HTTP 200، لكنها رجعت HTML عامًا متطابقًا؛ لا يثبت ذلك عرض صفحة خاصة أو إتمام الحذف.
- يجب التحقق من تجربة متصفح فعلية ومن مسار الحذف داخل التطبيق قبل إرسال المتجر. لا تغييرات على ميزة الحذف تمت ضمن هذه الحزمة.

## حدود هذا الفحص

فحص الملفات المحلية لا يثبت إعدادات مزودي الخدمة في الإنتاج أو Edge Functions غير الموجودة في المستودع. لم تُرسل إشعارات أو مكالمات أو مدفوعات اختبارية، ولم تُقرأ أو تُعدّل قاعدة الإنتاج.
